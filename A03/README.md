# Analysis of XML/HTML files

This simple program that searches the files and prints all names of the found compounds. 

## Libraries
This program needs the BeautifulSoup library.
This library can be installed using ```pip install beautifulsoup4```.

## How to run the program
### 1. Clone the repository
```git clone https://github.com/ludmilahamrle-natur/ci2.git```
```cd ci2/A03```

### 2. Create an enviroment
```python3 -m venv .venv```
```source .venv/bin/activate```

### 3. Run the script
```python nist_parser.py nist_benzidine.html```
