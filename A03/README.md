# Analysis of XML/HTML files

This simple program that searches the files and prints all names of the found compounds. 

## Libraries
This program needs the BeautifulSoup library.
This library can be installed using `pip install beautifulsoup4`.

## Running the program
1. You need to have a `nist_benzidine.html` file for the program. This file needs to be in the same directory as this program.
2. Go in terminal to the folder where is your program and your html file 
   for linux: `cd /home/user/projects/ci2/A03`
   for Windows: `cd /home/user/projects/ci2/A03`. 
3. Run the program in terminal `python3 nist_parser.py`.
