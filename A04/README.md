# A04 - CSV to SQLite
This program creates an SQL database and gets the total population of Southern Europe from the file country.csv.

## How to run the program
### 1. Clone the repository
git clone https://github.com/ludmilahamrle-natur/ci2.git
cd ci2/A04

### 2. Create the SQL database and run the script
python3 db.py country.csv

### 3. Run the script
After the database is created, the script can be run using only this:
python3 db.py
