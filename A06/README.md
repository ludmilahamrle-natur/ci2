# A06 -  Graphs with matplotlib (Jupyter)
This script contains a python script that reads a CSV and creates a graph in a .png file.

## How to run the program
### 1. Clone the repository
```git clone https://github.com/ludmilahamrle-natur/ci2.git```

```cd ci2/A06```
### 2. Create enviroment + install requirements
```python3 -m venv .venv```

```source .venv/bin/activate```

```python3 -m pip install -r requirements.txt```
### 3. Run the script
```python3 graph.py```
